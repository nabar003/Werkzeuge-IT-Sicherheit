## Hashsets (NSRL / RDS)

Hashsets dienen der Klassifikation bekannter Dateien in der digitalen Forensik. Die National Software Reference Library (NSRL) stellt sogenannte RDS-Hashsets bereit, 
die als Referenzdatenbank für die Identifikation unverdächtiger oder bekannter Dateien genutzt werden.

## Lernziele
- Verständnis der Rolle von Hashsets in der Forensik
- Nutzung von RDS-Hashsets zur Klassifikation
- Einordnung von Dateien in „bekannt“, „unbekannt“, „verdächtig“

## Relevanz
Pflicht für professionelle Datenträger-Forensik, Standard in DFIR-Labs und Ermittlungsbehörden.
