## Security Information and Event Management (SIEM) dient der zentralen Sammlung und Analyse sicherheitsrelevanter Ereignisse.

## Lernziele
- Aufbau einer Logging-Architektur
- Erkennen von Anomalien
- Nutzung von Open-Source-SIEM

## Relevanz
Wichtig für SOC-Betrieb, Monitoring und Incident Detection.

## Inhalt
Elastic-OpenSearch

Schwachstellenscanner  
OT-Security
